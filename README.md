# A CRM APPLICATION FOR THE CHAI SHOP & CO

## Project Overview

This project is a Salesforce-based CRM application developed for The Chai Shop & Co.

## Main Features

- Customer Account Management
- Enterprise Account Management
- Custom Salesforce Objects and Fields
- Record Types and Page Layouts
- Validation Rules
- Email Templates and Email Alerts
- Automated Birthday Email Notifications
- Customer Account Sales Report
- Enterprise Account Sales Report
- Customer vs Enterprise Sales Dashboard

## Technology Used

- Salesforce CRM
- Salesforce Lightning
- Salesforce Flow
- Salesforce Reports and Dashboards

## Project Status

The CRM application has been configured and demonstrated in a Salesforce Developer Edition environment.
